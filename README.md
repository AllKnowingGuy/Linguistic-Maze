# Linguistic Maze

Linguistic Maze - игра, основанная на реальных событиях. Студент-лингвист всегда
готовится к прохождению практики: но никогда не знает, чего от нее ожидать.
В этой игре познаются все грани возможного и невозможного для лингвиста Высшей школы экономики!

## Установка

Если у вас ещё нет Poetry, установите его (см. [официальную документацию](https://python-poetry.org/docs/#installation)).

После установки проверьте версию:
```bash
poetry --version 
```

## Использование

Чтобы запустить игру, введите в строку терминала:
```bash
poetry run python src/Main.py
```
