# Linguistic Maze

Linguistic Maze - игра, основанная на реальных событиях. Студент-лингвист всегда
готовится к прохождению практики, но никогда не знает, чего от неё ожидать.
В этой игре познаются все грани возможного и невозможного для лингвиста Высшей школы экономики!

## Клонирование репозитория и установка зависимостей

> Для работы игры необходим Python 3.13 или версия выше. Управление зависимостями осуществляется через библиотеку `poetry`.

Если у вас ещё нет рабочей папки репозитория, склонируйте в свою систему:
```bash
git clone https://github.com/AllKnowingGuy/Linguistic-Maze.git
```

Всю подробную иинформацию об установке вы можете найти в [Инструкции по установке](docs/INSTALL.md).

Если у вас ещё нет `poetry`, установите его (также см. [официальную документацию](https://python-poetry.org/docs/#installation)).

Чтобы установить библиотеку:

1. Введите в строку терминала:
```bash
pip install poetry
```

> На Windows также можно использовать winget:
> ```bash
> winget install Poetry.Poetry
> ```

2. Проверьте скачивание:
```bash
poetry --version 
```

3. Чтобы окружение создавалось прямо в папке проекта, выполните:
```bash
poetry config virtualenvs.in-project true
```

4. Установите зависимости:
```bash
poetry install
```

## Использование

Чтобы запустить игру, введите в строку терминала:
```bash
poetry run python src/Main.py
```

Управление ведётся в зависимости от прогресса игры:

- Лабиринт – стрелки клавиатуры или WASD (перемещение по клеткам).

- Диалоги – нажмите **Enter** для продолжения реплики. Для выбора варианта ответа кликните мышью по нужной кнопке. 
Если появляется поле ввода, введите текст с клавиатуры и затем нажмите **Enter**.
Нажмите **Esc**, чтобы пропустить анимацию и показать текст полностью.

- Задания (Challenge) – выбирайте варианты мышью или вводите текст в поле ввода. Для перехода между вопросами нажимайте мышью на 
кнопки навигации.

## Особенности

- *Три игровых режима*

Лабиринт – перемещайтесь по комнатам, взаимодействуйте с монстрами и ищите выход.

Диалог – общайтесь с монстрами, выбирайте ответы или вводите свой текст – это влияет на сюжет.

Задания – отвечайте на вопросы по лингвистике (фонетика, социолингвистика, компьютерная лингвистика, нейролингвистика).

- *Респекты и артефакты*

За правильные ответы вы получаете респекты – это своего рода очки счёта. Ошибаетесь – респекты снимаются. Если их слишком мало, дверь выхода не пустит вас дальше. Некоторые задания дают артефакты (например, дудку, стрелу, гармошку...), которые позволяют "задобрить" двери.

- *Случайная генерация комнаты*

Каждый раз стены образуют новый узор, монстры появляются в разных местах, а сложность комнат варьируется – игра не надоедает, а прохождение каждый раз идёт по‑новому.

- *Музыкальное сопровождение*

У каждого режима своя музыка, а в диалогах с монстрами звучат особые треки. Переходы между некоторыми сценами синхронизированы с музыкой для плавного погружения.

- *Настройка управления*

Вы можете переназначить клавиши для перемещения, взаимодействия и пропуска анимации прямо в главном меню. Настройки сохраняются в файле config.json.

## Архитектура

main.py — модуль запуска кода.

assets/ — ресурсы:

- data/ — JSON-файлы диалогов, заданий и комнат лабиринта;
- fonts/ — TTF-файлы шрифтов, используемых внутри игры;
- images/ — спрайты, UI, тайлы лабиринта;
- models/ — папки ресурсов языковых моделей, используемых для проверки некоторых ответов;
- music/ — звуковое сопровождение.

docs/ — внутренняя документация.

tests/ - тесты для запуска игры.

src/ — модули исходного кода:

- assetscreation.py — загрузка ресурсов;
- config.py — настройки;
- storyscript.py — сюжет и переходы;
- util.py — утилиты;
- level_building/ — классы данных (лабиринт, диалог, задания, проверщик, враги, кнопки);
- playstates/ — игровые режимы (лабиринт, диалог, задание, меню).

config.json — конфигурация пользователя.

README.md — пользовательская документация.
