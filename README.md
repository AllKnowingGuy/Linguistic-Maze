# Linguistic Maze

Linguistic Maze - игра, основанная на реальных событиях. Студент-лингвист всегда
готовится к прохождению практики: но никогда не знает, чего от нее ожидать.
В этой игре познаются все грани возможного и невозможного для лингвиста Высшей школы экономики!

## Установка

> Для работы игры необходим Python 3.11 или версия выше. Управление зависимостями осуществляется через библиотеку `poetry`.

Если у вас еще нет рабочей папки репозитория, склонируйте в свою систему:
```bash
git clone https://github.com/AllKnowingGuy/Linguistic-Maze.git
```

Всю подробную иинформацию об установке вы можете найти в [Инструкции по установке](docs/INSTALL.md).

Если у вас ещё нет `poetry`, установите его (также см. [официальную документацию](https://python-poetry.org/docs/#installation)).

Чтобы установить библиотеку:

1. Введите в строку терминала:
```bash
pip install poetry
```

> На Windows также можно использовать winget:
> ```bash
> winget install Poetry.Poetry
> ```

2. Проверьте скачивание:
```bash
poetry --version 
```

3. Чтобы окружение создавалось прямо в папке проекта, выполните:
```bash
poetry config virtualenvs.in-project true
```

4. Установите зависимости:
```bash
poetry install
```

## Использование

Чтобы запустить игру, введите в строку терминала:
```bash
poetry run python src/Main.py
```

Управление ведется в зависимости от прогресса игры:

- Лабиринт – стрелки клавиатуры или WASD (перемещение по клеткам).

- Диалоги – **Enter** для продолжения реплики. Для выбора варианта ответа кликните мышью по нужной кнопке. 
Если появляется поле ввода, введите текст с клавиатуры.

- Задания (Challenge) – выбирайте варианты мышью или вводите текст в поле ввода. Для перехода между вопросами используйте 
кнопки навигации.

## Особенности

- *Три игровых режима*

Лабиринт – перемещайтесь по комнатам, уклоняйтесь от монстров и ищите выход.

Диалог – общайтесь с монстрами, выбирайте ответы или вводите свой текст – это влияет на сюжет.

Задания – отвечайте на вопросы по лингвистике (фонетика, социолингвистика, нейролингвистика, компьютерная лингвистика).

- *Респекты и артефакты*

За правильные ответы вы получаете респекты – это своего рода очки жизни. Ошибаетесь – респекты снимаются. Если их станет слишком мало, игра закончится. Некоторые задания дают артефакты (дудка, стрела, гармошка), которые позволяют пропускать трудных монстров без выполнения их заданий.

- *Случайная генерация сложности*

Каждый раз монстры появляются в разном порядке и с разной сложностью комнаты – игра не надоедает, а прохождение каждый раз идёт по‑новому.

- *Музыкальное сопровождение*

У каждого режима своя музыка, а в диалогах с монстрами звучат особые треки. Переходы между сценами синхронизированы с музыкой для плавного погружения.

- *Настройка управления*

Вы можете переназначить клавиши для перемещения, взаимодействия и пропуска анимации прямо в главном меню. Настройки сохраняются в файле config.json.

- *Прогресс сохраняется*

Если вы закрыли игру, накопленные респекты и артефакты не пропадут – при следующем запуске вы продолжите с того же места.

## Архитектура

assets/ — ресурсы:

- data/ — JSON-файлы диалогов и заданий;
- images/ — спрайты, UI, тайлы лабиринта;
- music/ — звуковое сопровождение.

docs/ — внутренняя документация.

tests/ - тесты для запуска игры.

src/ — исходный код:

- Main.py — модуль запуска;
- AssetsCreation.py — загрузка ресурсов;
- Config.py — настройки;
- StoryScript.py — сюжет и переходы;
- Util.py — утилиты;
- levelBuilding/ — классы данных (лабиринт, диалог, задания, враги, кнопки);
- playstates/ — игровые режимы (лабиринт, диалог, задание, меню).

config.json — конфигурация пользователя.

README.md — пользовательская документация.
