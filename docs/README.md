# Linguistic Maze

## Особенности

- *Совмещение трёх режимов*

Лабиринт – перемещение по клеткам, поиск выхода, взаимодействие с монстрами.

Диалог – интерактивное общение с монстрами: выбор вариантов ответа, текстовый ввод, влияние на сюжет.

Задания – проверка знаний лингвистики через текстовые или множественные ответы, начисление респектов и выдача артефактов.

- *Система респектов и артефактов*

Респекты накапливаются за правильные ответы или более подходящие. Артефакты выдаются некоторыми монстрами и упрощают выход из комнаты.
Если респекты падают ниже порога, дверь не пускает игрока дальше. 

- *Проверка ответов через чекеры*

Поддерживаются различные способы проверки: точное совпадение с одним из вариантов ответа (plainequality), соответствие регулярным выражениям (rematch),
анализ тональности с помощью предобученной модели BERT (sentiment_rubert) и проверка того, что все слова существуют (existing_words).

- *Динамическая сложность и тематика*

Комнаты лабиринта имеют уровни сложности (0, 1, 2). Параметры генерации комнат и пороги респектов для прохождения через двери
зависят от сложности комнат.

- *Музыкальное сопровождение*

Для разных состояний (диалог, задание, лабиринт) используются отдельные музыкальные треки. Диалоги могут быть 
«зловещими» – в них играет музыка монстра, синхронизированная с окончанием диалога.

- *Современный подход к импортированию*

Проект использует Poetry для управления зависимостями, Pygame для графики, звука и управления, библиотеки Hugging Face 
(transformers, torch) для задач анализа текста и русскоязычную версию библиотеки Pymorphy для проверки существующих слов.
