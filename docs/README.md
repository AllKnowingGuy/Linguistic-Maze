# Linguistic Maze

## Особенности

- *Совмещение трех режимов*

Лабиринт – перемещение по клеткам, поиск выхода, уклонение от монстров.

Диалог – интерактивное общение с монстрами: выбор вариантов ответа, текстовый ввод, влияние на сюжет.

Задания – проверка знаний лингвистики через текстовые или множественные ответы, начисление респектов и выдача артефактов.

- *Система респектов и артефактов*

Респекты накапливаются за правильные ответы или более подходящие. Артефакты позволяют пропускать некоторые задания, а 
также смотрятся на выходе из комнаты. Если респекты падают ниже порога, наступает проигрыш. 

- *Проверка ответов через чекеры*

Поддерживаются различные способы проверки: точное совпадение (plainequality), поиск лингвистических терминов 
(ling_terms), регулярные выражения (wordmatch), анализ тональности с помощью предобученной модели BERT (sentiment_rubert).

- *Динамическая сложность и тематика*

Комнаты лабиринта разделены на уровни сложности (0, 1, 2). Задания подбираются случайно из пула, учитывая текущую 
сложность и сильные темы игрока (фонетика, социолингвистика, нейролингвистика, компьютерная лингвистика).

- *Музыкальное сопровождение*

Для разных состояний (диалог, задание, лабиринт) используются отдельные музыкальные треки. Диалоги могут быть 
«зловещими» – в них играет музыка монстра, синхронизированная с окончанием диалога.

- *Современный подход к импортированию*

Проект использует Poetry для управления зависимостями, Pygame для графики и звука, библиотеки Hugging Face 
(transformers, torch) для задач анализа текста.

## Добавление диалога

Чтобы добавить метаданные о диалоге:

1. Создайте JSON-файл в `assets/data/dialogues/` (например, my_dialogue.json).
2. Используйте поле `jump` для перехода на другую реплику (индекс). Если есть `choices`, реплика будет ждать выбора.

## Работа с артефактами и респектами

В JSON-файле заданы поля:

- **correctrpoints** – сколько респектов даётся за правильный ответ.

- **incorrectrpoints** – сколько снимается (отрицательное число).

- **artifact** – название артефакта, выдаваемого за правильный ответ.

Артефакты хранятся в списке player["artifacts"]. Для пропуска задания через артефакт используйте метод `Challenge.can_skip_with_artifact`.
