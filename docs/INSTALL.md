# Инструкция по установке

## Системные требования

- Python: версия 3.13.
- Операционная система: Windows 10/11, Linux, macOS.
- Оперативная память: не менее 4 ГБ (для работы модели transformers может потребоваться больше).
- Графика: видеокарта с поддержкой OpenGL (требуется для Pygame).
- Интернет: необходим при первом запуске игры для загрузки модели rubert-base-cased-russian-sentiment (объём загрузки ≈ 400 МБ).

## Установка с помощью poetry

Poetry — менеджер зависимостей, который создаёт изолированное окружение для проекта. 

Если у вас ещё нет `poetry`, установите его (также см. [официальную документацию](https://python-poetry.org/docs/#installation)).
Убедитесь, что у проекта ещё не установлено виртуальное окружение.

Чтобы установить библиотеку:

1. Введите в строку терминала:
```bash
pip install poetry
```

> На Windows также можно использовать winget:
> ```bash
> winget install Poetry.Poetry
> ```

2. Проверьте скачивание:
```bash
poetry --version 
```

> Если команда не распознаётся, добавьте в переменную PATH каталог, содержащий `poetry.exe` 
(обычно `%USERPROFILE%\AppData\Local\Packages\PythonSoftwareFoundation.Python.3.13_*\LocalCache\local-packages\Python313\Scripts`), 
и перезапустите терминал.

3. Перейдите в корневую папку проекта и выполните команду, которая настроит создание виртуального окружения внутри папки проекта (удобно для IDE):
```bash
poetry config virtualenvs.in-project true
```

4. Установите зависимости:
```bash
poetry install
```

5. Запустите игру:
```bash
poetry run python src/playstates/Main.py
```

Если возникают сложности в установке виртуального окружения с помощью `poetry`, 
возможна установка через `.venv/` с использованием `requirements.txt`.

## Обновление игры

При использовании `poetry` для виртуального окружения (рекомендуется):
```bash
git pull
poetry update
```

При использовании виртаульного окружения `.venv/`
```bash
git pull
pip install -r requirements.txt --upgrade
```

## Запуск тестов

Перед запуском тестов убедитесь, что виртуальное окружение установлено.

Чтобы запустить все тесты, введите в строку терминала:
```bash
poetry run pytest
```

Чтобы запустить конкретный тест, введите в строку терминала:
```bash
poetry run pytest <путь к файлу>
```

Чтобы запустить тест с подробной информацией о тестировании, введите в строку терминала:
```bash
poetry run pytest -v
```

Чтобы запустить тест с отображением локальных переменных при ошибке, введите в строку терминала:
```bash
poetry run pytest -l
```

Чтобы запустить тесты, которые упали в предыдущем тестировании:
```bash
poetry run pytest --lf
```
