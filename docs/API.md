# API

Данный файл описывает форматы данных и публичные методы, которые используются для расширения 
игры Linguistic Maze. С его помощью вы сможете создавать собственные диалоги, задания, уровни и даже добавлять 
новые типы проверки ответов.

> ## Глоссарий
> Диалог — сцена общения игрока с персонажем (монстром).
> 
> Задание (Challenge) — набор вопросов/задач, которые игрок решает в специальном режиме.
> 
> Респекты — внутриигровая валюта, накапливается за правильные ответы и тратится при ошибках.
> 
> Комната - место, где игрок ходит и ищет выход. У каждой комнаты своя уникальная тематика, счётчик респектов и артефактов.
> 
> Артефакты — предметы, позволяющие пропускать некоторые задания или дающие пропуск на выходе из комнаты.

## Диалоги

Диалоги хранятся в папке `assets/data/dialogues/` в формате JSON. Пример: `intro.json`.

Пример общей структуры файла:
```bash
{
  "left": "Протагонист",             
  "right": "Монстр",                  
  "rightsprite": "monsters/level_0/enemy_at_exit.png",
  "ominous": false,                  
  "music": "Monster.wav",                        
  "challenge": false,    
  "lines": [ ... ]
}
```

### Поля верхнего уровня (диалог)

| Поле | Тип | Описание |
|------|---|----------|
| `left` |  | Имя левого персонажа |
| `right` | str | Имя правого персонажа |
| `rightsprite` | str | Путь к спрайту правого персонажа относительно `assets/images/dialogue/` |
| `ominous` | bool | Если `true`, перед диалогом проигрывается зловещая музыка |
| `music` | str | Имя файла из `assets/music/` для фоновой музыки на время диалога (опционально) |
| `rpoints` | int | Количество респектов, начисляемых после завершения диалога |
| `challenge` | bool | Если `true`, после диалога автоматически запускается задание |
| `lines` | array | Массив реплик (объектов) |

### Поля реплики (объект внутри `lines`)

| Поле | Тип           | Описание |
|------|---------------|----------|
| `speaker` | str             | `"left"` или `"right"` |
| `text` | str           | Текст реплики |
| `bg` | str           | Фон: `"PREVSCREEN"` (предыдущий кадр) или путь к файлу относительно `assets/images/dialogue/backgrounds/` |
| `music` | str           | Меняет музыку: путь к файлу из `assets/music/` или `STOP` для остановки |
| `jump` | int / null    | Индекс следующей реплики (0‑база). `-1` — завершить диалог, `null` — обычный переход к следующей |
| `rpoints` | int           | Респекты, начисляемые после этой реплики |
| `cancelchallenge` | bool          | Если `true`, отменяет текущее задание |
| `nextroom` | bool          | Если `true`, после реплики перейти на следующую комнату |
| `restartroom` | bool          | Если `true`, после реплики перезагрузить текущую комнату |
| `action` | object / null | Объект с действием (выбор или сохранение текста) |

### Поля `action` (внутри реплики)

| Поле | Тип | Описание                                                                                                                                              |
|------|-----|-------------------------------------------------------------------------------------------------------------------------------------------------------|
| `type` | str    | `"choosefrom"` (кнопки выбора) или `"savetyped"` (сохранение)                                                                                         |
| `options` | array | Массив строк — варианты для кнопок (только для `type: "choosefrom"`)                                                                                  |
| `jumps` | array | Массив целых чисел, соответствующих каждому варианту. Указывает индекс следующей реплики после выбора определенного варианта. `-1` — завершить диалог |

## Задание

Задания хранятся в `assets/data/challenges/level_N/`. Каждый файл представляет собой JSON-объект с одним массивом. 
Пример: `enemy_at_exit.json`.

Пример общей структуры файла:
```bash
{
    "windows": [
        {
            "title": "ЗАДАНИЕ 1",
            "text": "Ответь на главный вопрос мира.",
            "action": {
                "type": "savetyped",
                "answers": ["42", "67"],
                "checker": "plainequality",
                "correctcomments": ["Имеет смысл...", "Или нет?"],
                "incorrectcomments": ["Эх, не шаришь.", "Подумай ещё."],
                "correctrpoints": 2,
                "incorrectrpoints": -2
            }
        },
        {
        },
        {
            "title": "ЗАДАНИЕ 2",
            "text": "Почему?",
            "action": {
                "type": "choosefrom",
                "options": [...],
                "answers": ["Оно не имеет структуры"],
                "checker": "plainequality",
                "correctcomments": ["Признайся, сам код для этого писал?", "Как ты это понял?"],
                "incorrectcomments": ["Не повезло, не угадал.", "Мимо!"],
                "correctrpoints": 3,
                "incorrectrpoints": -1
            }
        }
    ]
}
```
### Поля задания (объект внутри `windows`)

| Поле | Тип | Описание |
|------|-----|----------|
| `title` | str    | Заголовок задания |
| `text` | str    | Текст вопроса |
| `image` | str    | (опционально) Путь к изображению относительно `assets/images/challenge/` |
| `action` | str    | Объект с параметрами проверки ответа |

### Поля `action` (объект внутри `windows`)

| Поле | Тип | Описание                                                                   |
|------|-----|----------------------------------------------------------------------------|
| `type` | str    | `savetyped` (поле ввода) или `"choosefrom"` (кнопки выбора)                |
| `options` | array | Массив строк — варианты для выбора (только для `type: "choosefrom"`)       |
| `answers` | array | Массив правильных ответов (строки или регулярные выражения)                |
| `checker` | str    | Имя чекера: `plainequality`, `ling_terms`, `wordmatch`, `sentiment_rubert` |
| `correctrpoints` | int | Респекты за правильный ответ                                               |
| `incorrectrpoints` | int | Респекты за неправильный ответ (обычно отрицательное)                      |
| `artifact` | str    | Название артефакта, выдаваемого в диалогах после испытаний и заданий       |
| `correctcomments` | array | Массив строк — случайные комментарии при правильном ответе                 |
| `incorrectcomments` | array | Массив строк — случайные комментарии при неправильном ответе               |
| `threshold` | float | Порог для `sentiment_rubert` (по умолчанию 0.6)                            |

## Поддерживаемые чекеры введенного текста при прохождении заданий

- `plainequality` – сравнивает введённый текст с каждым значением из answers после удаления пробелов по краям и без учёта 
регистра. Если хотя бы одно совпадение, ответ правильный.
- `ling_terms` – ищет в ответе регулярное выражение (лингвист|язык|лингв|термин|фонет|социо|нейро). Возвращает True, если 
найдено совпадение.
- `wordmatch` – применяет регулярные выражения из answers к ответу игрока. Каждое выражение проверяется независимо; ответ 
считается правильным, если хотя бы одно совпало.
- `sentiment_rubert` – использует модель для анализа тональности. Возвращает `True`,
если оценка положительности (score) превышает threshold (по умолчанию 0.6). 
При ошибке (например, нет интернета) возвращается fallback-проверка на ключевые слова хорошо, помощь.

## Добавление нового чекера

Чтобы добавить собственный способ проверки, отредактируйте метод `check_current_answer` в классе **Challenge** 
(`src/levelBuilding/Challenge.py`). Добавьте новую ветку elif:

```bash
elif checker == 'my_checker':
    ...
    correct = some_condition(user_input)
```

После этого в JSON-файл можно использовать "checker": "my_checker".
